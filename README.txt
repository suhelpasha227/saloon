# Pasha Unisex Salon Website

A responsive one-page salon website built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — website sections and appointment form
- `style.css` — responsive layout and styling
- `script.js` — mobile navigation, gallery lightbox and WhatsApp booking
- `assets/` — the reference images supplied for the website

## Run locally
1. Extract the ZIP.
2. Open the `pasha_unisex_salon_website` folder in VS Code.
3. Install/open the VS Code **Live Server** extension if needed.
4. Right-click `index.html` → **Open with Live Server**.

You can also open `index.html` directly in a browser for a quick preview.

## WhatsApp booking
The appointment form opens WhatsApp to **+91 97585 81374** with the entered details pre-filled. The customer still needs to press Send in WhatsApp, and the salon must confirm the booking.

## Before publishing
- Confirm the business phone number and address.
- Confirm current service names and prices.
- Replace reference poster photos with your own final salon photos if you have higher-quality versions.
- Add your real social media links and business hours if desired.

This is a static front-end website. It does not store bookings in a database; requests are sent through WhatsApp.
